# Python Library Handbooks

Personal reference handbooks for Python libraries commonly used in
scientific computing, data analysis, and machine learning.

These handbooks were created as study and reference material while
working with various Python libraries.

## Handbooks

- [NumPy](./NumPy%20Handbook.md)
- [Pandas](./Pandas%20Handbook.md)
- [SciPy](./SciPy%20Handbook.md)
- [Scikit-Learn](./Scikit-Learn%20Handbook.md)
- [Other APIs](./Other%20APIs.md)

## Purpose

The goal of these handbooks is to provide a practical reference for
library APIs, concepts, functions, and usage patterns encountered
during coursework and projects.

The material is primarily written as personal notes and references
rather than as replacements for the official documentation.

## Libraries

### NumPy

Notes on numerical computing with NumPy, including arrays,
indexing, broadcasting, mathematical operations, and related APIs.

### Pandas

Notes on data manipulation and analysis using Pandas, including
Series, DataFrames, indexing, filtering, grouping, and common
operations.

### SciPy

Notes on scientific computing functionality provided by SciPy.

### Scikit-Learn

Notes on machine learning tools and APIs provided by Scikit-Learn,
including preprocessing, models, clustering, and evaluation.

### Other APIs

Miscellaneous notes covering additional Python APIs and libraries.

---

These handbooks are continuously evolving as I encounter new
libraries and concepts.
